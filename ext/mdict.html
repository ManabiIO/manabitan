Importing MDict dictionaries

Experimental support. Compatibility depends on the dictionary. Keep your original files; Manabitan converts a copy for its own dictionary storage.

Choose the complete set together

The .mdx file contains definitions. Matching .mdd files contain optional resources, such as images and stylesheets. Select all files for one dictionary in the same selection or drop:

Dictionary.mdx
Dictionary.mdd
Dictionary.1.mdd
Dictionary.2.mdd

The extra MDD volumes are only needed when your dictionary supplies them. Keep the publisher's filenames and do not rename unrelated resources to make them match.

MDD files cannot be imported alone or attached later. To add omitted resources, remove only that dictionary and reimport its complete set. There is no need to use Delete All.

Dictionary audio is not enabled by the current import flow. Selecting an MDD with audio does not enable that audio. The separate pronunciation-audio settings are unchanged.

Import and check the result

  1. Open Settings > Dictionaries, choose Configure installed and enabled dictionaries, then Import.
  2. Choose or drop the MDX and all matching MDD files together. Local files start importing immediately. Keep the Settings page open until installation finishes.
  3. Check that the dictionary appears as installed and is enabled for your active profile. Conversion progress reaching 100% does not prove installation succeeded.
  4. Open Search and try a known headword, an alias, and an entry with an image or table. Check again after opening a fresh Search page.

Local conversion does not upload your dictionary to a conversion server. Imports from URLs do make network requests. External links in definitions can open websites.

The file picker also accepts Yomitan-format ZIP dictionaries. A ZIP containing loose MDX/MDD files is not a Yomitan dictionary: extract that set first, then select its files together.

With Advanced settings enabled, dictionaries added through Import from URLs stay in the pending list until you click Import. Downloading files locally is an alternative when a hosting page cannot be imported directly.

Compatibility and troubleshooting

Some compression, encryption, and format variants are unsupported. Scripts and interactive dictionary widgets are not preserved, and layout or styling can differ. Successful import is not a guarantee that every source feature survived conversion.

Show troubleshooting steps

Missing images or styling

Check that the original matching MDD files were selected with the MDX. Adding them in a second import will not update an installed dictionary. Also check whether the original dictionary depends on separate files that are not in its MDD resources. Even a complete set can contain unsupported presentation features.

Files do not match

Import one dictionary set at a time and remove duplicate selections. Keep the original filenames. Report a pairing failure with the exact MDX/MDD names rather than renaming unrelated files.

Truncated data or an integrity error

Try a fresh copy of the complete original set. Renaming or changing the extension cannot repair its contents. Retain the exact error message for a compatibility report.

Conversion times out

The conversion client has a three-minute limit, including file reads. Try one dictionary at a time. Large dictionaries may need a compatible external converter that produces a Yomitan ZIP. Do not remove unrelated installed dictionaries.

The dictionary is installed but no result appears

Check the active profile, the dictionary's enabled toggle, and the selected language. Try an exact headword known to exist in the original dictionary. Report missing definitions separately from missing media.
