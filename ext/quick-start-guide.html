Manabitan Quick Start Guide

Open settings and install dictionaries

Open the toolbar popup, then Settings. Choose your language and open Get recommended dictionaries… in the Dictionaries section. Start with a definition dictionary.

To import your own compatible dictionary package, open Configure installed and enabled dictionaries… and use Import. Enable it in the active profile after the import finishes. See the dictionary guide for formats, schedules, and backups.

Look up a word

On a normal webpage with selectable text, hold Shift and move the pointer over a word. Grant website permission and reload the page when necessary. Browser settings/store pages and image-only text can be unavailable to scanning.

The speaker plays available audio from your configured sources. The search page can look up text using installed dictionaries. See scanning and audio settings for customization.

For PDFs, use the Manabitan PDF Viewer. It requires a selectable text layer; it does not add OCR.

Connect Anki

Install AnkiConnect in Anki, keep Anki running, and enable Anki integration in Manabitan. Configure a deck, note type, and fields, then create one test note. Follow the Anki guide for note-type setup, duplicates, media, and custom templates.

Moving from another extension

Keep the old extension and its data while testing. Export settings and retain the original dictionary packages. Settings JSON, dictionary packages, and whole-database backups are different; a Yomitan JSON database is not a Manabitan SQLite backup.

Follow Moving from Yomitan or Moving from Yomichan. Disable the other extension's scanning to avoid duplicate popups without uninstalling it.
