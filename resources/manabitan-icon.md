# Manabitan icon

The approved mark is a single white ま on Manabi red. The kana is the outlined KaoriGel Bold glyph, with no runtime font dependency. Colors: red `#bd2331`, warm white `#fff9f8`.

`manabitan-icon.svg` is the vector master. Matching PNGs at 16, 19, 32, 38, 48, 64 and 128 pixels are shipped in `ext/images`. The legacy `ext/images/yomitan-icon.svg` filename is retained for compatibility and contains the same approved mark. Historic upstream artwork in `resources/icons.svg` is not used by the extension manifest.
