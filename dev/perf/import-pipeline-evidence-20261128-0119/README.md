## What overlap does and does not establish

Current-group deduplication precedes compression dispatch. Logical reference reservation then permits metadata publication and record encoding while compression continues. Content and record owners are joined with `Promise.allSettled` before the ordered sink advances. Parser-produced independent shared buffers permit producer progress without lending the parser's live heap to the sink.

The worker's `source-consumed` message marks input gathering, before compression output exists. The database wrapper exposes reservation and terminal completion; borrowed-source retirement remains tied to terminal completion. Removing that lifetime boundary would be a separate scheduling change.

The analysis joins dispatch, worker handling, source-consumed sends, compressed-result sends and both receiver handlers by exact `traceId`. Many record-field and checksum samples occur after workers sent all outputs but before the import worker handled the final result. There are no exact markers for per-group metadata publication, record completion or the final promise join. No such timestamps are inferred. Sample counts are not milliseconds, negative profile intervals are retained, and diagnostic jobs are not substituted for the unprofiled paired cohorts.

The raw-cache locality model redirects the observed raw comparisons into 90,794,154 decoded bytes even with one decode per touched block. Two explicit existing-48-MiB-LRU completion scenarios produce 182 loads and 179,138,967 decoded bytes. These are untimed accounting scenarios, not browser decode measurements or exhaustive ordering bounds. In-flight raw sources could avoid some fallback loads. The existing content import overlay already owns compressed frames by reference.

## Native checksum route proof

The initial candidate diagnostic in [run 46104742882](https://github.com/ManabiIO/manabitan/actions/runs/46104742882), source `f3fd2373de6e74f6243008ff3f1f68703d688973`, contains 30 leaf samples in `lookup_hash_update` and one in `lookup_hash_finish`, under the expected hasher/envelope ancestry. Exact packaged WASM export indices and function-body offsets bind the sampled functions to the candidate. The module SHA256 is `60237c98d16196db00161af3a896aae4d2f8104f63401d5617d17f895e752b94`.

This source precedes the intrinsic typed-array-kind admission correction. It establishes execution of the native algorithm on ordinary input; it is not final-head performance qualification. Subsequent native cohort outcomes must be assessed separately, including source validation, raw timing, controls and memory coverage.

## Archive contents and reproduction limits

- `cache-native-overlap-evidence-0119.tar.gz` is the unchanged 58-member follow-up bundle. It retains all four raw browser traces/reports, source/package identities, exact message joins, native export binding, locality census, ownership review and reproduction scripts.
- `profile-metadata-review-subset.tar.gz` retains 48 of the earlier 49 members byte-for-byte: the original profile analyses, compression attribution, full rejected metadata-screen observations, capture script and source snapshots. The sole omitted member is the 14,876,086-byte generated V8 metadata input capture. Its exact hash and regeneration recipe remain retained; no timed observation was omitted. The subset is explicitly distinct from the original archive, whose hash remains recorded.
- `additional-investigations.tar.gz` retains the complete CDict source audit, CRC first-use scripts and every observation/control, original bundle receipts, index and this packager. The CRC screen uses Node 22.22.0 and the unchanged production verifier; all first/subsequent results match independent Node zlib. Its empty-input base-initialization screen includes the retained 1.2122 ms outlier. No candidate timing, all-corpus CRC parity or browser gain is claimed from that diagnostic.

Every included archive was read back and hashed before publication. `files.sha256.json.txt` records outer hashes, review members, the omitted regenerable capture and original archive identity. Unpack each bundle into a separate directory initially; shared profile paths deliberately preserve the same original evidence. Follow each included index for complete replay requirements, including the locked fixtures and exact source checkout. Failed acquisition, earlier adapter-fidelity limitations, script preflight corrections and noisy observations remain disclosed in the retained reports.
