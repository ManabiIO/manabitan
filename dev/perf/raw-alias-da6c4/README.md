# VNDB raw-reference alias component (research only)

This directory contains an unexecuted, prospectively specified experiment. It does not change product source and does not establish a production ownership capability or a whole-import gain.

The earlier exact VNDB route proof found eight mixed content-name groups. Their175 raw row references point to only two canonical raw records (617 and 338 bytes). A per-current-group alias requires eight physical compressed entries and 2,983 input bytes in this pinned corpus. Making each affected record group physically uniform may let the unchanged record sink retain its original whole native lookup payload. Canonical metadata and the original content prefix are preserved.

## Fixed experiment

The protocol runs 36 observations in 12 ABC blocks, using all six orders twice. Every observation is a fresh Node 22.22.0 child with no component warmup. A and C are the unchanged sink. B includes all canonical content reads, the existing codec/session alias append, private record-reference overlay construction, the real record sink, and both stores' finalization. The four compression workers start through the normal lifecycle equally in every arm. A one-block alias uses the existing synchronous owner-codec path. The actual VNDB index-worker transport is retained through a Node file-handle bridge.

The component starts from the exact completed baseline content file (7,533,449 bytes). Its appended tail positions are real file positions for this replay; they are not each group's original import-time positions. The original ten selected groups retain their global firstId gaps and native key arenas. No padding, precomputed alias payload, source threshold change, worker-count change, or global promotion cache is introduced.

Candidate eligibility is bounded before timing: one already-selected compact block family, a genuinely complete native whole prepared map in the immutable capture, at most 64 canonical raw-v6 entries, and at most 64 KiB alias input per mixed group. Uniform controls use the unchanged sink. Ordinary 4 GiB offset-span fallback remains in the unmodified record store.

## Acquisition and identity

The orchestrator checks every harness hash, exact runtime commit/tree, generated parser/codec assets, dictionary lock, and preserved evidence archive member before corpus acquisition. It then downloads the exact checksum-fixed VNDB ZIP and runs the archived actual native parser/global canonical dedup/content routing logic with explicit path and capture-hook adaptations.

All 170 regenerated route projections, original prepared-map hashes, and the complete route witness must equal the original proof. The completed content file must retain SHA-256 f50a48e23056054a13f90dfa7aad53ba3a80a6f6e7125289a5ad52dc2f9f686e. Only groups 0, 1, 2, 87, 91, 92, 105, 123, 126, 139 are retained. Binary backings, content seed, and all capture JSON together must remain within 64 MiB. This is a new capture with a new manifest identity; it is not presented as recovery of the inaccessible original post-v2 capture files.

The graph serializer preserves object, Map, ArrayBuffer, and typed-view aliases. The loader restores the existing synchronous resolved-reference factory origin. That origin is not treated as an immutability guarantee: each observation owns its own process/loaded graph, and all source buffers, names, columns and maps are hash-guarded before and after use.

## Storage and verification

The Node adapter performs lazy real-file reads, incremental staged writes, fsync and rename on close, and exclusive synchronous index handles shared across worker transports. It is a research transport, not a browser emulator. In particular, arbitrary construction of a new native Blob from its lazy File subclasses is outside the actual store paths tested here. File read-only modes are not a browser-concurrency qualification. The deterministic adapter gates must pass before acquisition.

The elapsed endpoint joins both store finalizations. Process user/system CPU deltas are diagnostics around the same endpoint; overlapping phase clocks are not summed. After worker termination, a separate quiescence check rejects surviving file resources, writer locks or staging files before verification begins.

Every observation strictly parses the persisted sidecars, verifies all 400,000 rows' IDs, byte keys, equality sentinels, scores and normalized sequences, decodes every distinct referenced canonical definition and every changed alias, checks native route filters, and performs exact lookups through a fresh reader. B's ten whole lookup payloads must match the original native map bytes. The original content prefix must remain exact. A/C files must match after masking only their independently verified random generation nonce fields; B has its own deterministic physical layout and recorded size deltas.

No seeded global metadata/cache structure is replayed in the timed component. Captured canonical reference columns stay immutable, and the constructor-only database metadata/cache remain empty and unchanged. Production publication, rollback, media handling and a receiver-to-sink immutable lease remain later gates if this screen advances.

## Commands and outcome

Run the research workflow, or invoke:

    python3 dev/perf/raw-alias-da6c4/run.py --repository /absolute/repository --workspace /new/workspace --output /new/output

The repository must contain the preserved v1/v2 evidence archives and installed locked dependencies. The runner never retries a failed cohort. Every setup log, incomplete receipt, raw observation, source binding, capture and physical output is retained under the output directory.

The fixed advance criteria require at least 10 ms and 10% paired median savings against both controls, at least 9 of 12 faster pairs each, lower summed B time, strictly negative upper endpoints of both descriptive 95% bootstrap intervals, and a control-drift bound. All source, physical and semantic checks must also pass. Passing only advances the idea to production ownership design and separately bound browser qualification. No timing result is claimed by this source handoff.
