The implementation validates every current source span and persisted offset synchronously. It uses a module-private origin brand only to rule out proxy records, intrinsic getters to establish actual view and buffer kinds, and private disjoint numeric buffers. Shared source bytes remain permitted. Generic, mutable accessor, shared-numeric, aliased, detached, duplicate, out-of-order, or otherwise unproven inputs retain the original validator. No validation result crosses an asynchronous boundary.

## Acquisition

Each dictionary has two independent hosted cells. Each uses three excluded warmups and twelve complete ABC blocks, with fresh browser profiles for every observation. The second host reverses every block. A and C share the same immutable baseline package. The timing boundary is the ordinary file-input change through completed post-UI import work. No timing or product overlay is used.

`protocol.json` fixes commit trees, artifacts, fixture and runtime identities, member changes, statistics, and qualification gates before acquisition. `run.py` rejects unexpected changes and incomplete receipts. There are no retries, appended samples, tail exclusions, host pooling, or control subtraction. All raw failures and unattempted entries remain visible.

The native-only replay is explicitly omitted because it bypasses changed database registration code. All native artifacts and their manifest must be byte-identical to baseline. Complete units, focused adversarial registration cases, scoped lint, main and test types, and every dry build target run against the exact candidate. Complete semantic browser receipts, exhaustive media, and four separate process-tree memory observations remain required. Separate CPU traces follow all timing and memory observations.

## Prior component evidence and limits

A completed twelve-triplet registration-only Node screen led to additional intrinsic-brand hardening. The exact hardened source then completed a separately fixed six-triplet confirmation: all eighteen child processes checked lookup and cleanup behavior. Candidate cold CPU medians were 5.84 ms versus 12.66 ms and 14.59 ms for A/C; paired medians were 0.490 and 0.425. The unchanged control ratio was 1.153 and is retained. These measurements isolate registration work; they establish no complete-import speedup.

179 focused tests and scoped lint passed locally. An earlier local full suite was canceled after runtime hardening invalidated its exact-source identity; it is not counted as passing. Hosted exact-candidate correctness is required.

Promotion requires a repeatable complete-import benefit against both unchanged controls on both hosts, assessed against control variation, plus all correctness and memory gates. A correct or faster component alone is insufficient.
