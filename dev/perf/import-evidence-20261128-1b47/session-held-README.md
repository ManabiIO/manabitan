## Compression interpretation and exact cost

The complete capture is 103 JMdict frames and 385 Jitendex frames. Every baseline frame reproduces byte-for-byte, and every retained level decodes exactly through the production decoder and independent libzstd. The original frame payloads are reproducible and omitted; all manifests, size/decode oracles, timings, failures and reconstruction scripts are included.

The diagnostic's fresh-context phase creates one CCtx per full corpus and already reuses it across all frames. The retained phase performs two whole-corpus warmups before repeated corpora. Production also reuses a context per compression worker, but four workers each receive only a subset of frames on first import. Thus production reuse does not make the weak fresh-context result irrelevant or causally explain the stronger retained result. The serial per-frame timer also excludes parallel scheduling, gathering, storage and publication. The full independent interpretation is `compression-level/pr-worthiness-reassessment.md`.

At the complete browser receipt denominators, level −2 increases JMdict by exactly **312,404 bytes / 0.717832%**, Jitendex by **750,018 bytes / 1.111692%**, and VNDB by zero. These pass the prospective 2% ceiling but do not prove the tradeoff worthwhile. The decoder controls are too noisy for a tight non-regression claim. The reported WASM memory figure is capacity, not live-context allocation or browser peak memory.

All original local worker-test failures remain, including the observed SIGKILL. The exact standalone worker sequence passes and current hosted source validation passes. Unavailable cgroup evidence prevents claiming the local failure was proven OOM.

## Scope, source provenance and failures

Local public-sink replay includes the actual compressed-source parser pipeline, deduplication, codec workers, record encoder and persisted file bytes. It omits native browser synchronous handles, SQL setup/publication, UI and exhaustive browser media/restart verification. Native-only and compression-only protocols have still narrower endpoints. Ordinary baseline browser times and separate traces are orientation only, never a comparison.

The bundle retains complete raw observations, warmups, identical-code controls, excluded setup failures, acquisition markers, declarations, proof records, validation logs and independent reviews for the selected experiments. No outliers, unfavorable tails or failed cohort are removed. Source snapshots/patches and a small native checkpoint Git pack preserve the unpublished candidate implementations; the pack needs the accepted baseline ancestry. The source/driver binding report distinguishes exact retained driver matches from any unresolved historical provenance.

Hosted status is frozen to the **2026-11-28 06:32:35 UTC** snapshot. A complete timing schedule may still fail another qualification gate, and that failure remains material. In particular, the newly completed pipeline Jitendex study is retained with its baseline memory-sampling coverage failure; it is not relabeled a qualified improvement. Its independent review also establishes that the overlap never activates: all 11 candidate observations have zero deferred operations, adopted bytes and owned bytes, with 22 borrowed groups each. Later hosted results require a separately identified supplement. Validation belongs to the exact source head shown in its receipt.

## Contents and deliberate omissions

Original workspace-relative file paths and bytes are preserved. The external manifest includes every member's SHA-256 and size and binds the complete deterministic tar.gz. It is external to avoid a circular self-hash exception. The selector and packager reject symlink files and directory components before reading payload bytes. The 976 relocated compression payloads are **not followed**; their complete original path/size/hash receipt is included.

Omitted are dictionary ZIPs/media, large source slabs, regenerated frame payloads, full browser traces, installed dependencies, compiler/browser distributions, full databases, and duplicate extension/build outputs. The omissions section records original file hashes/byte counts where captured, immutable source/artifact or fixture identities, and reconstruction commands. If an original hash or exact historical helper is unavailable, the limitation is explicit. No later reconstruction is presented as original evidence.

Small ordinary browser receipts and extracted trace analyses are included. Full trace hashes and the extraction script allow the original diagnostic to be recovered from its recorded artifact. Source locks and original full output/source digests bind the dictionary captures without copying the archives into the repository.
